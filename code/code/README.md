# Code map

- `data_acquisition/`: GEE and AppEEARS acquisition scripts.
- `preprocessing/build_w36_inputs.py`: W6–W48 input preparation.
- `canonical_pipeline.py`: W36 model pipeline.
- `model_comparison/`: comparison and ablation models.
- `baselines/`: Ridge and climatology baselines.
- `evaluation/`: known-site and unseen-site evaluation.
- `uncertainty/`: clustered bootstrap analyses.
- `interpretation/shap_geoshap_analysis/`: SHAP and GeoSHAP analyses.

- `water_energy_analysis/`: primary and sensitivity GAMM analyses for the water–energy environmental context.
