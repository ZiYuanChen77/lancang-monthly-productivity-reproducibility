# lancang-monthly-productivity-reproducibility

Reproducibility materials supporting the analyses reported in manuscript SRS-D-26-00418.

## Repository contents

- `code/`: source code for data acquisition, preprocessing, model training, evaluation, uncertainty analysis, and interpretation.
- `public_data/`: public research data and data documentation used to support the reported analyses.

Additional information on the code, data fields, and data sources is provided in the README and documentation files within the corresponding folders.
