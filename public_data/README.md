# Public research data

- `model_input/monthly_model_input.csv`: monthly modelling data for 247 sites, 2001–2025.
- `model_input/study_sites_247.csv`: study-site and MOD17 sampled-pixel coordinates.
- `model_input/unseen_site_fold_assignment.csv`: coordinate-clustered holdout folds.
- `mod17_quality/appeears_MOD17A2HGF_point_sample.csv`: MOD17A2HGF.061 composite values and quality fields.
- `annual_reference/MOD17A3HGF_site_year.csv`: annual MOD17A3HGF site-year data.
- `source_assets/vegetation_roi.gpkg`: study-region vegetation strata.

Field definitions are in `documentation/DATA_DICTIONARY.md`; public data sources are in `documentation/DATA_SOURCES.md`.
